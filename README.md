# AI-Driven Gearbox Fault Diagnostic Rig

**[Download the complete prepared project](project-source.zip)** — extract this archive to restore the original project folder structure. Key source and report files are also available below for browsing.

Embedded acquisition and motor-control components from a multidisciplinary rig that classifies healthy, chipped-tooth, and missing-tooth gearbox conditions.

## Technologies

Arduino / ESP32 / vibration sensing

## Explore the project

The available code covers accelerometer acquisition and VFD control. The PC diagnostic application and trained model are not in the supplied folder.
